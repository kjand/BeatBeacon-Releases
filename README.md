# Beat Beacon

Beat Beacon is a visual metronome plug-in for your DAW, from [MM Productions](https://www.mmproductions.no/).

It follows the host's transport, tempo and time signature. It shows every beat clearly and highlights the downbeat, so you have a silent timing reference while you record, edit or perform. An optional click, with an accented beat 1, plays the same beats you see.

- Beat display synced to the host playhead, with beat 1 highlighted
- Optional click with adjustable click volume, accent volume and tone
- Quarter, eighth, triplet and sixteenth subdivisions
- Click routing: stereo, left only or right only
- Compact and stage views, with a resizable window

## Download

Downloads are on the [Releases](https://github.com/kjand/BeatBeacon-Releases/releases) page. Each release has installation instructions and the requirements.

Beat Beacon is currently available for Windows (64-bit) as a VST3 plug-in.
